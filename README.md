# ClipForge · 网页视频剪辑器

一个**完全运行在浏览器里**的视频剪辑软件：无需安装、无需后端、打开即用。支持多轨时间线剪辑、分割、字幕、滤镜、音量调节与一键导出 WebM 成片。

> 🎯 技术亮点：原生 Canvas 实时合成 + Web Audio 混音 + MediaRecorder 录制导出，零依赖、零构建。

## 🚀 快速开始

### 方式一：本地直接打开（推荐预览）

用 Chrome / Edge 浏览器直接打开 `index.html` 即可使用。

> 建议通过本地静态服务器打开（可选）：
> ```bash
> # 任选其一
> python -m http.server 8080
> npx serve .
> ```
> 然后访问 `http://localhost:8080`

### 方式二：部署到 GitHub Pages

1. 把本仓库推送到 GitHub；
2. 仓库 Settings → Pages → 选择 `main` 分支根目录部署；
3. 几分钟后即可通过 `https://<你的用户名>.github.io/clipforge/` 访问。

## 🎮 使用流程

1. 点击顶部 **「＋ 导入媒体」**，选择视频 / 图片 / 音频文件；
2. 在左侧素材库点击素材，自动添加到视频轨或音频轨末尾；
3. 在时间线上选中片段 → 右侧属性面板调整位置、滤镜，或点击 **预设效果** 一键套用调色风格；
4. 播放头定位到分割点 → 点击 **「✂ 分割」** 切开片段；
5. 点击 **「＋ 字幕」** 添加字幕，双击时间线上的字幕片段快速编辑文字；
6. **添加转场**：点击时间线上两个相邻片段之间的 ✧ 圆形按钮，选择转场类型（叠化 / 黑场 / 滑动 / 擦除 / 缩放 / 模糊 / 圆形 / 旋转 / 分裂…）并调节时长；
7. 完成剪辑后点击 **「🚀 导出成片」**，等待实时合成完成即可下载 WebM 视频。

### 快捷键

| 按键 | 功能 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `S` | 在播放头处分割选中片段 |
| `Del` / `Backspace` | 删除选中片段 |
| `←` / `→` | 上一帧 / 下一帧 |
| `Home` | 回到开头 |

## ⚙️ 技术说明

- **渲染**：固定 1920×1080 渲染画布，多轨按时间顺序合成，cover 模式铺满、保持原始比例；
- **转场**：转场发生在两段相邻片段之间的时间窗内（B 提前淡入），支持叠化 / 黑场 / 白场 / 滑动 / 擦除 / 缩放 / 模糊 / 圆形 / 旋转 / 分裂 12 种效果，时长 0.1–2s 可调，随项目 JSON 保存与恢复；
- **滤镜**：使用 Canvas 2D `ctx.filter`（亮度/对比度/饱和度/模糊/灰度/棕褐/色相），8 种一键调色预设；
- **音频**：每个音视频片段经 `createMediaElementSource` 接入 Web Audio 图，通过独立 GainNode 混音（预览走扬声器、导出走 MediaStreamDestination）；
- **导出**：`canvas.captureStream(30)` + 音频流合流，MediaRecorder 实时录制，自动选择 VP9/VP8 + Opus 编码；
- **兼容性**：需要支持 `MediaRecorder`、`AudioContext`、Canvas `filter` 的现代浏览器（推荐最新版 Chrome / Edge）。

## 📌 已知限制

- 导出采用实时渲染，导出时长 = 项目时长（不可倍速）；
- 项目文件（JSON）不包含媒体二进制，换设备后需重新关联素材；
- 目前分辨率固定 1920×1080 / 30fps。
